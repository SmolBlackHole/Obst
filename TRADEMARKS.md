The software and documentation licenses in this repository do not grant rights
to the OBST name, logos or other project branding. SmolBlackHole reserves those
rights to the extent provided by applicable law.

This is a project name-use policy, not a claim that OBST is currently a
registered trademark. Do not use the registered-trademark symbol (`®`).

## Uses that do not require permission

You may use the name truthfully to:

- refer to the OBST format or this project;
- state that an implementation reads, writes or supports a named OBST version;
- describe a product as compatible with OBST when it actually conforms to the
  canonical specification; and
- preserve required attribution and historical notices in forks.

These uses must not imply sponsorship, endorsement or official project status.

## Uses that require permission

Without prior written permission, do not:

- use OBST as the primary name of another product, service or organization;
- use the project's logos or branding in a way that suggests official status;
- present a modified or incompatible format as OBST; or
- publish a fork as the canonical OBST specification or an official OBST
  release.

Forks and independent implementations are welcome. A fork that changes the
format or presents a separate product must use its own name and branding.

## Technical authority

The versioned [OBST format specification](docs/format.md) in the canonical
project repository defines valid OBST container bytes. Independent
implementations may implement that contract. The documentation license and
this policy do not authorize third parties to publish competing definitions as
official OBST revisions.

Third-party Extensions remain free to define contracts in their own namespace.
The `obst.*` Extension namespace, OBST container version names and official
codenames are reserved for this project.

For permission beyond this policy, contact the repository owner through the
[SmolBlackHole GitHub profile](https://github.com/SmolBlackHole).
